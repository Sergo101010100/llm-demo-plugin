# Проверки
1. Проверь что сгенерированный Junit-тест полностью соответствует исходному тест-кейсу из нашего обсуждения.
2. Если в шагах нет реализации - предложи свою
3. Проанализируй на:
    - Полноту покрытия всех шагов тест-кейса
    - Корректность формулировок шагов
    - Наличие проверки ожидаемого результата
    - Отсутствие лишних, пустых или пропущенных шагов
    - Синтаксическую корректность Junit-сценария
    - Отсутствие лишнего текста и пояснений, кроме самого автотеста
    - Наличие ручных действий и проверок в виде комментариев
4. Убери все пустые шаги. Пустых шагов быть не должно

Исправь сгенерированный Junit-тест и верни только исправленный вариант, без пояснений.
