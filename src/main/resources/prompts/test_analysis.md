Проанализируй {{testType}}:
1. Определи тестируемую функциональность
2. Выдели ключевые действия
3. Укажи ожидаемый результат
4. Сформируй список ключевых слов (однословные и короткие многословные фразы, без дубликатов, обязательно на русском языке)
5. Укажи тип теста. Только одним из следующих вариантов:  UI, DB, REST, KAFKA, OTHER

Ответ в формате JSON без форматирования:
{
"description": "...",
"keywords": ["...", "..."],
"type": "..."
}

Примеры:
{
"description": "Проверка создания нового пользователя. Успешная регистрация",
"keywords": ["создание", "пользователи", "регистрация", "успех"],
"type": "UI"
}

{
"description": "Проверка отправки сообщения в Kafka. Успешная отправка",
"keywords": ["kafka", "сообщения", "отправка", "успех"],
"type": "KAFKA"
}

{
"description": "Проверка создания задания. Ошибка создания при некорректном URL",
"keywords": ["задание","создание","ошибка", "url"],
"type": "UI"
}
