### Основные правила
1. Формат вывода, если другое не задано в дополнительных инструкциях:
```java
<аннотации теста>
public void test_<ключ теста> ()
{
   // Step 1: <Оригинальное описание шага>
          Allure.step("<Действие с параметрами 1>", () -> {
              // Реализация действия 1
              <код выполнения>

             //Необходимая проверка 1
             <код проверки>
          });
 // Step 2: <Оригинальное описание шага 2>
          Allure.step("<Действие с параметрами 2>", () -> {
              // Реализация действия 2
              <код выполнения 2>

             //Необходимая проверка 2
                <код проверки>
          });
}
```

2. Обязательные элементы:
    - У метода обязательно должны быть добавлены аннотации БЕЗ ИЗМЕНЕНИЙ
    - Логирование действий через библиотеку Allure
    - Если в примерах нет кода проверки или кода реализации - сгенерируй код сам

### Пример преобразования ручного теста в автотест
Ручной тест:
Открыть страницу "/login"
Ввести логин "admin"
Проверить заголовок "Dashboard"
Сгенерированный автотест:
```java
@io.qameta.allure.TmsLink("T1")
@org.junit.jupiter.api.Test
@org.junit.jupiter.api.DisplayName("Проверка формы авторизации")
public void test_T1 (){
// Step 1: Открыть страницу "/login"
Allure.step("Открыть страницу \"/login\"", () -> {
    page.open("/login");
});
// Step 2: Ввести логин "admin"
Allure.step("Ввести логин \"admin\"", () -> {
    loginForm.setUsername("admin");
});
// Step 3: Проверить заголовок "Dashboard"
Allure.step("Проверить заголовок \"Dashboard\"", () -> {
    String title = page.getTitle();
    assertThat(title).isEqualTo("Dashboard");
});
